# v1.0.1 release audit

## Scope

This patch changes only the explanatory colony mechanism visualization and product metadata. The
frozen v0.1 and v1.0 protocols, source data, reports, machine-readable results, and scientific claims
remain unchanged.

## Evidence review

- Rechecked the distinction between permanent chitinous parent–daughter connections and later
  non-adhesive steric branch retention against the primary 2023 and 2024 papers.
- Confirmed that broken parent–daughter connections must not be presented as reforming.
- Confirmed that the detailed entanglement quantification is not a five-population longitudinal
  endpoint and therefore must not drive transfer-specific percentages.
- Removed visual conventions that could be mistaken for measured bond types, stress, or observed
  fracture events.

## Reproduction and interface checks

- Regenerated the committed browser data from the frozen analysis inputs.
- Compared regenerated artifacts with the published reports.
- Exercised 195 visualization states: five populations × 13 sampled transfers × three views.
- Verified tree, fracture, and retained-contact invariants in every state.
- Inspected representative early colony, intermediate packing, and late retained-fracture states.
- Checked the responsive layout and reduced-motion contract.

## Remaining limits

Topology, local load, fracture location, and retained contacts remain illustrative. The visualization
does not reconstruct microscopy, infer branch-level forces, estimate fracture probabilities, or add
new biological observations.

The release is tied to the tagged commit recorded by GitHub Release v1.0.1.
